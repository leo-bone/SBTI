❓ 常见问题
python3 mirofish.py start 报错，怎么办？
最常见的原因是依赖未安装。运行以下命令：
pip3 install networkx openai anthropic zep-cloud python-dotenv requests tqdm --user
安装完再重试启动命令。
提示 .env 中 API Key 未填写？
回到步骤③，把 Key 填入生成器，复制命令在终端运行一次。如果手动编辑，运行：
nano /Users/leo/WorkBuddy/20260329130323/MiroFish/.env
按方向键移动到 LLM_API_KEY=your_api_key_here 这行，把 your_api_key_here 替换成你的真实 Key，Ctrl+O 保存，Ctrl+X 退出。
仿真结果在哪看？
仿真完成后，MiroFish 界面会自动显示报告，包括：智能体交互图谱、关键事件时间线、最终结论。报告同时保存在 backend/outputs/ 目录下，可随时查看。
能用 DeepSeek 替代阿里云模型吗？
完全可以。在步骤③的 「LLM 模型名称」填 deepseek-chat，「Base URL」填 https://api.deepseek.com/v1，Key 使用 DeepSeek 的 Key 即可。DeepSeek-V3 价格更低，推理效果也很好。
